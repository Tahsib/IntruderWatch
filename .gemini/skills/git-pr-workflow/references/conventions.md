# Git Conventions for IntruderWatch

## Branch Naming
- **Features:** `feat/short-description`
- **Bug Fixes:** `fix/short-description`
- **Refactoring:** `refactor/short-description`
- **Infrastructure/Monitoring:** `infra/short-description`

## Commit Messages
Use **Conventional Commits** format:
- `feat: <message>`
- `fix: <message>`
- `docs: <message>`
- `chore: <message>`

## PR Guidelines
- Always include a summary of changes.
- Mention verification steps taken (e.g., "Verified via Docker logs").
